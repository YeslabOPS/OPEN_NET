# UI 回归测试步骤

> 本文档用于验证前端 UI 所有可见交互功能是否正常。
> 
> **前置条件**：
> - 后端已启动：`cd backend && uvr un uvicorn main:app --reload`
> - 前端已启动：`cd frontend && npm run dev`
> - 浏览器打开 `http://localhost:5173`
> - `.env` 中已配置正确的 `DEEPSEEK_API_KEY`

## TC-1: 全局导航

### TC-1.1 侧边栏菜单显示
1. 确认左侧显示 "Super Agent" 标题
2. 确认菜单包含三个入口：`对话`、`知识库`、`设备管理`
3. 确认当前页面对应菜单项高亮

### TC-1.2 页面切换
1. 点击 `知识库` → 页面跳转到知识库管理
2. 点击 `设备管理` → 页面跳转到设备管理
3. 点击 `对话` → 页面跳转回对话
4. 确认切换过程无白屏报错

---

## TC-2: 对话页 (`/`)

### TC-2.1 初始状态
1. 确认页面打开后显示空的对话区域
2. 确认显示机器人图标和 "Super Agent 网络巡检助手" 提示文字
3. 确认输入框存在，Placeholder 显示 "输入你的问题..."
4. 确认发送按钮存在且为禁用状态（无输入时）

### TC-2.2 发送消息
1. 在输入框输入文字 "你好" → 确认发送按钮变为可用
2. 点击发送按钮
3. 确认用户消息气泡出现（蓝色背景，靠右）
4. 确认 Agent 响应气泡出现（灰色背景，靠左）
5. 确认响应内容为 Markdown 格式渲染
6. 确认侧边栏出现 "查看计划" 按钮
7. 确认自动滚动到底部

### TC-2.3 流式响应
1. 输入 "介绍一下网络巡检" 并发送
2. 确认 Agent 响应是逐步出现的（流式效果）
3. 确认流式过程中输入框被禁用
4. 确认流式完成后输入框恢复可用

### TC-2.4 计划展示
1. 输入 "检查核心路由器CPU状态" 并发送
2. 点击侧边栏的 "查看计划" 按钮
3. 确认弹出一个计划卡片
4. 确认显示意图标签（如 "网络巡检"）
5. 确认显示子任务列表（带步骤序号）
6. 确认显示进度百分比
7. 再次点击 "查看计划" → 确认计划面板收起

### TC-2.5 新对话
1. 点击侧边栏 "新对话" 按钮
2. 确认消息被清空
3. 确认回到初始空白状态

### TC-2.6 清空对话
1. 发送一条消息
2. 点击 "清空对话" 按钮
3. 确认对话消息被清除
4. 确认回到初始状态

### TC-2.7 错误处理
1. 断开后端服务（停止后端进程）
2. 发送消息 → 确认前端显示错误提示
3. 重新启动后端
4. 发送消息 → 确认恢复可用

## TC-3: 知识库页 (`/knowledge`)

### TC-3.1 文档列表
1. 点击侧边栏 "知识库" 进入知识库页面
2. 确认页面标题为 "知识库管理"
3. 确认显示文档表格，包含列：`文档名称`、`状态`、`标签`、`操作`
4. 确认初始显示 3 篇文档：
   - 网络设备巡检基础指南
   - 常见网络故障排查手册
   - OSPF 路由协议配置指南
5. 确认所有文档状态为 "未编译"

### TC-3.2 编译全部
1. 点击 "编译全部" 按钮
2. 确认按钮显示加载状态
3. 等待编译完成
4. 确认文档状态变为 "已编译"（绿色标签）
5. 确认弹出成功提示

### TC-3.3 编译单个
1. 对任意一篇文档，点击其操作列的 "编译" 按钮
2. 确认该文档编译成功后状态更新
3. 已编译的文档的 "编译" 按钮应为禁用状态

### TC-3.4 文档预览
1. 点击任意文档名称
2. 确认右侧弹出 Drawer 抽屉
3. 确认 Drawer 标题为文档名
4. 确认显示文档内容（Markdown 渲染）
5. 点击 Drawer 外部或关闭按钮 → 确认 Drawer 关闭

### TC-3.5 知识查询
1. 找到 "知识库查询" 卡片
2. 在输入框中输入 "如何进行网络巡检？"
3. 点击 "查询" 按钮
4. 确认查询结果展示在下方区域
5. 确认结果包含参考来源数量

### TC-3.6 刷新和重建索引
1. 点击 "刷新" 按钮 → 确认文档列表刷新
2. 点击 "重建索引" 按钮 → 确认索引成功提示
3. 重新查询知识库 → 确认查询功能正常

---

## TC-4: 设备管理页 (`/devices`)

### TC-4.1 空状态
1. 点击侧边栏 "设备管理" 进入设备管理
2. 确认页面标题为 "设备管理"
3. 确认显示空表格（无设备数据）
4. 确认显示操作按钮：`刷新`、`添加设备`

### TC-4.2 添加设备
1. 点击 "添加设备" 按钮
2. 确认弹出 Modal 对话框，标题为 "添加设备"
3. 确认表单包含字段：设备名称、主机地址、SSH 端口、用户名、密码、设备类型、描述
4. 不填写必填项，点击 "保存" → 确认表单校验提示
5. 填写完整设备信息：
   - 设备名称: `测试路由器-01`
   - 主机地址: `192.168.1.1`
   - SSH 端口: `22`
   - 用户名: `admin`
   - 密码: `pass123`
   - 设备类型: `路由器`
6. 点击 "保存"
7. 确认 Modal 关闭
8. 确认表格中出现新添加的设备
9. 确认显示设备信息：名称、主机地址、端口、用户名、类型

### TC-4.3 编辑设备
1. 点击设备的 "编辑" 按钮
2. 确认 Modal 打开，标题为 "编辑设备"
3. 确认表单预填了设备原有信息
4. 修改设备名称为 "测试路由器-02"
5. 点击 "保存"
6. 确认表格中设备名称已更新

### TC-4.4 测试连接
1. 点击设备的 "测试" 按钮
2. 确认按钮显示加载旋转状态
3. 等待连接测试完成
4. 确认弹出提示（成功或失败）
5. 确认按钮恢复正常

### TC-4.5 删除设备
1. 点击设备的 "删除" 按钮
2. 确认弹出确认对话框 "确定删除?"
3. 点击 "取消" → 确认设备未被删除
4. 再次点击 "删除" → 点击 "确定"
5. 确认设备从表格中消失

### TC-4.6 刷新
1. 添加一条设备到数据库
2. 点击 "刷新" 按钮 → 确认表格刷新显示新设备
