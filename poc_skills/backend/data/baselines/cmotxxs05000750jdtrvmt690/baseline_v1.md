# generic 配置基线

## 基线信息
- 版本: v1
- 生成时间: 2026-05-06
- 适用设备类型: generic
- 模板: 阿里云

## 关键配置项

### 1. 设备可达性
| 参数 | 期望值 | 说明 |
|:-----|:------|:-----|
| 设备IP | 8.138.90.155 | 巡检目标设备IP地址 |
| 设备类型 | generic | 设备类型标识 |
| 巡检Agent | test agent | 执行巡检的Agent名称 |

### 2. 命令执行环境
| 参数 | 期望值 | 说明 |
|:-----|:------|:-----|
| 命令执行环境 | 支持bash命令 | 设备应支持bash命令执行环境 |
| 命令兼容性 | 支持display命令 | 设备应兼容华为/华三系列命令格式 |

### 3. 巡检执行状态
| 参数 | 期望值 | 说明 |
|:-----|:------|:-----|
| 命令执行成功率 | 100% | 所有命令应成功执行 |
| 命令执行超时 | < 100ms | 单条命令执行时间应小于100ms |

## 安全基线要求
- 设备应支持SSH或Telnet等远程管理协议
- 设备应具备命令执行权限，避免出现"command not found"错误
- 设备操作系统应支持标准网络设备命令集（如display系列命令）

## 性能基线要求
- 单条命令执行时间应小于100ms
- 总巡检执行时间应小于500ms
- 设备应能同时处理至少4条命令的并发执行

## 告警阈值
- 当命令执行成功率低于100%时触发告警
- 当单条命令执行时间超过100ms时触发告警
- 当总巡检执行时间超过500ms时触发告警
- 当出现"command not found"错误时触发告警
