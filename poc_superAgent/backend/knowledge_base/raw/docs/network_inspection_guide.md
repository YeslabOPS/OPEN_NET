# 网络设备巡检基础指南

## 概述
网络巡检（Network Inspection）是网络运维的基础工作，定期巡检有助于发现潜在问题、保障网络稳定性。

## 巡检内容

### 1. 设备状态检查
- **CPU 使用率**：正常情况下应低于 70%，持续高于 90% 需要关注
- **内存使用率**：正常情况下应低于 80%
- **设备温度**：不同设备有不同阈值，通常高于 75°C 需要告警
- **电源状态**：检查是否双电源供电，确认电源模块正常

### 2. 端口状态检查
- **端口 UP/DOWN 状态**：确认关键端口状态正常
- **端口错误计数**：检查 CRC 错误、碰撞计数等异常
- **带宽利用率**：检查端口流量是否接近上限
- **光模块状态**：检查光功率、温度、电压

### 3. 路由协议检查
- **OSPF 邻居状态**：确认 OSPF 邻居为 Full 状态
- **BGP 会话状态**：确认 BGP 会话为 Established 状态
- **路由表条目**：检查路由条目是否正常

### 4. 日志检查
- **系统日志**：检查错误级别和告警级别日志
- **安全日志**：检查登录失败、配置变更等

## 巡检频率建议
- 核心设备：每日一次
- 汇聚设备：每周一次
- 接入设备：每月一次
- 特殊时期（重大活动）：加密巡检频率

## 常用命令
```bash
# 查看 CPU 使用率
show process cpu

# 查看内存使用率
show process memory

# 查看端口状态
show interface status

# 查看 OSPF 邻居
show ip ospf neighbor

# 查看 BGP 会话
show bgp summary
```
