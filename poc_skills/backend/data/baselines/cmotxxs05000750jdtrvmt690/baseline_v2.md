# generic 配置基线

## 基线信息
- 版本: v1
- 生成时间: 2026-05-06
- 适用设备类型: generic
- 模板: 阿里云

## 关键配置项

### 1. 设备连接与认证
| 参数 | 期望值 | 说明 |
|:-----|:------|:-----|
| 设备类型 | generic | 通用设备类型 |
| 模板 | 阿里云 | 使用阿里云模板进行巡检 |

### 2. 命令执行环境
| 参数 | 期望值 | 说明 |
|:-----|:------|:-----|
| 命令执行环境 | bash | 设备使用bash shell环境，非传统网络设备CLI |

## 安全基线要求
- 确保设备支持通过SSH进行远程管理
- 确保设备bash环境可正常执行命令

## 性能基线要求
- 命令执行响应时间应小于100ms（当前display version命令执行耗时82ms，display interface命令执行耗时71ms，display cpu-usage命令执行耗时68ms，display memory命令执行耗时27ms）

## 告警阈值
- 当命令执行失败率超过0%时触发告警（当前巡检4条命令全部失败，失败率100%）
- 当命令执行超时超过500ms时触发告警
