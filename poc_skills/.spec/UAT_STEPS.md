## 应用启动方法

> **重要**：请按照以下步骤依次执行，确保所有服务正常运行后再开始测试。

### 一、环境要求

| 项目 | 要求 |
|------|------|
| Node.js | v18.x 或更高版本 |
| pnpm | v8.x 或更高版本 |
| 数据库 | SQLite 3（无需单独安装，随项目携带） |
| 操作系统 | Linux / macOS / Windows |

### 二、项目目录结构

```
poc_skills/
├── backend/                    # 后端服务
│   ├── prisma/
│   │   └── schema.prisma       # 数据库模型定义
│   ├── src/
│   │   ├── index.ts             # 后端入口
│   │   ├── routes/              # 路由
│   │   └── services/            # 服务层
│   ├── data/
│   │   └── baselines/           # 基线文档存储目录
│   └── package.json
│
├── frontend/                   # 前端服务
│   ├── src/
│   │   ├── App.tsx              # 前端入口
│   │   └── pages/               # 页面组件
│   └── package.json
│
└── .spec/                      # 规格文档目录
```

### 三、数据库初始化

#### 3.1 安装 pnpm（如未安装）

```bash
# 全局安装 pnpm
npm install -g pnpm

# 验证安装
pnpm --version
```

#### 3.2 安装依赖并生成 Prisma 客户端

```bash
# 进入后端目录
cd backend

# 安装依赖
pnpm install

# 生成 Prisma 客户端
pnpm prisma generate

# 初始化数据库（创建表结构）
pnpm prisma db push
```

#### 3.2 验证数据库初始化成功

执行成功后，终端会显示类似信息：
```
Your database has been set up and is ready to use.
Database tables created:
- Agent
- Skill
- Conversation
- Message
- SystemConfig
- AuditLog
- InspectionTemplate
- InspectionRecord
- InspectionSchedule
- Notification
- BaselineDocument
```

> **注意**：如果数据库文件不存在，会自动创建在 `backend/prisma/dev.db`

### 四、配置系统

#### 4.1 配置 API Key

系统需要配置 DeepSeek API Key 才能使用 Agent 智能分析功能。

1. 启动后端服务（见下一步）
2. 打开浏览器访问 `http://127.0.0.1:3000`
3. 进入「系统配置」页面
4. 找到 DeepSeek API Key 配置项
5. 输入您的 API Key
6. 点击「保存」

> **注意**：也可以直接在数据库中修改 `SystemConfig` 表的 `deepseek_api_key` 记录。

#### 4.2 环境变量配置（可选）

如需自定义配置，可创建 `backend/.env` 文件：

```env
# 数据库连接
DATABASE_URL="file:./prisma/dev.db"

# 服务端口
PORT=3001

# 前端地址（用于 CORS）
FRONTEND_URL=http://127.0.0.1:3000

# DeepSeek API Key
DEEPSEEK_API_KEY=your_api_key_here
```

### 五、启动后端服务

```bash
# 在 backend 目录下执行
cd backend

# 启动服务
pnpm dev
```

**预期输出：**
```
Server is running on http://localhost:3001
Prisma Schema loaded
Database connected successfully
Scheduler initialized with X tasks
```

### 六、启动前端服务

打开一个新的终端窗口：

```bash
# 进入前端目录
cd frontend

# 安装依赖
pnpm install

# 启动开发服务器
pnpm dev
```

**预期输出：**
```
  VITE v5.x.x  ready in xxx ms

  ➜  Local:   http://localhost:3000/
  ➜  Network: http://127.0.0.1:3000/
```

### 七、验证服务状态

| 服务 | 地址 | 验证方法 |
|------|------|----------|
| 前端 | http://127.0.0.1:3000 | 浏览器打开，显示登录页 |
| 后端 API | http://127.0.0.1:3001/api/health | 返回 JSON 状态 |
| 数据库 | backend/prisma/dev.db | 文件存在且有内容 |

### 八、常见问题排查

| 问题 | 解决方案 |
|------|----------|
| 数据库连接失败 | 检查 `backend/prisma/schema.prisma` 中的 `datasource db` 配置 |
| 端口被占用 | 修改 `.env` 中的 `PORT` 值 |
| Prisma 客户端错误 | 执行 `pnpm prisma generate` 重新生成 |
| 前端无法访问后端 API | 检查后端 CORS 配置是否允许 `http://127.0.0.1:3000` |
| Agent 分析功能不可用 | 检查 DeepSeek API Key 是否正确配置 |

### 九、快速重启

如需重启所有服务：

```bash
# 1. 停止现有服务（Ctrl+C）

# 2. 重启后端
cd backend && pnpm dev

# 3. 重启前端（新终端窗口）
cd frontend && pnpm dev
```
