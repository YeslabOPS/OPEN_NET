# 常见网络故障排查手册

## 1. 连通性故障

### 1.1 Ping 不通
**可能原因**：
- 物理链路断开
- IP 地址配置错误
- 路由缺失
- 防火墙/ACL 阻断

**排查步骤**：
1. 检查物理连接（光口/电口指示灯）
2. 检查 IP 配置（ipconfig/ifconfig）
3. 检查路由表（traceroute/tracert）
4. 检查 ACL 规则
5. 检查 ARP 表项

### 1.2 丢包严重
**可能原因**：
- 带宽不足
- 链路质量问题（光衰大、双工不匹配）
- 设备 CPU 过载
- 网络环路

**排查步骤**：
1. 检查带宽利用率
2. 检查端口错误计数
3. 检查设备 CPU 负载
4. 检查 STP 状态
5. 通过抓包分析流量

## 2. 性能故障

### 2.1 网络延迟高
**可能原因**：
- 链路拥塞
- 路由路径非最优
- 设备处理能力不足

**排查步骤**：
1. 使用 `ping` 测试延迟和抖动
2. 检查 MTR/traceroute 每跳延迟
3. 检查设备资源利用率
4. 检查 QoS 配置

### 2.2 带宽利用率异常
**可能原因**：
- 大流量应用（视频、下载）
- 病毒/蠕虫攻击
- 环路导致广播风暴

**排查步骤**：
1. 使用 `show interface` 查看流量统计
2. 使用 NetFlow/sFlow 分析流量构成
3. 检查是否存在环路

## 3. 安全故障

### 3.1 异常登录
**排查要点**：
- 查看登录日志、检查异常 IP
- 确认账号权限变更
- 检查 SSH/Telnet 配置

### 3.2 DDoS 攻击
**排查要点**：
- 检查流量异常突增
- 查看连接数统计
- 配置流量限制和 ACL
