# Super Agent POC - 任务拆分文档

> 本文档用于快速理解项目进度和当前阶段，新 session 可直接阅读此文件跟进。

---

## Phase 1: 项目初始化

### 1.1 创建后端项目结构
- 使用 uv init 初始化 Python 后端项目，创建 backend/ 目录

### 1.2 创建前端项目结构
- 使用 Vite + React + TypeScript 初始化前端项目，创建 frontend/ 目录

### 1.3 配置基础依赖
- 安装 FastAPI、uvicorn、ADK 等后端依赖，以及 Ant Design 等前端依赖

---

## Phase 2: ADK Agent 框架 + DeepSeek API

### 2.1 配置 DeepSeek API
- 在后端配置 DeepSeek API Key 和 base URL，支持流式响应

### 2.2 实现基础 Agent 类
- 创建 Gemini/DeepSeek Agent 实例，打通信道（Channel）

### 2.3 实现基础对话功能
- 支持用户消息 → Agent → 流式响应的端到端对话

---

## Phase 3: 知识库模块（Wiki 引擎 + RAG）

### 3.1 搭建 Wiki 引擎
- 实现 Wikipedia 搜索和摘要获取，支持中英文查询

### 3.2 实现 RAG 检索
- 将检索结果分块、向量化，存入向量数据库（Chroma）

### 3.3 集成知识库到 Agent
- Agent 具备调用知识库检索的能力，将结果纳入回答上下文

### 3.4 实现知识库管理 API
- 提供知识库的增删改查接口，支持批量导入

---

## Phase 4: SSH 工具模块（Paramiko + MCP）

### 4.1 实现 SSH 连接工具
- 使用 Paramiko 实现设备连接、命令执行和结果返回

### 4.2 实现 MCP Server
- 创建 MCP SSH 工具 Server，封装可被 Agent 调用的 SSH 工具

### 4.3 实现设备管理 API
- 提供设备的增删改查、连接状态管理接口

---

## Phase 5: 任务规划器（意图理解 + 分解）

### 5.1 实现意图识别
- Agent 具备识别用户意图的能力，判断是否需要执行网络巡检

### 5.2 实现任务分解
- 将复杂巡检任务分解为可执行的子任务步骤

### 5.3 实现执行调度
- 支持子任务按序执行，失败时跳过并记录，最终汇总执行结果

---

## Phase 6: 前端对话页面 + 计划可视化

### 6.1 实现对话界面
- 使用 Ant Design 组件实现聊天界面，支持消息发送和流式响应显示

### 6.2 实现计划可视化
- 展示 Agent 生成的任务执行计划和当前进度状态

### 6.3 实现历史记录
- 支持查看历史对话记录

---

## Phase 7: 前端知识库管理页面

### 7.1 实现知识库管理 UI
- 提供知识库文档的查看、添加、删除、搜索功能

### 7.2 实现设备管理 UI
- 提供 SSH 设备的增删改查和连接测试功能

---

## Phase 8: 集成联调 + 错误处理

### 8.1 端到端联调
- 前后端联调，确保 Agent 能正确调用知识库和 SSH 工具

### 8.2 实现错误处理
- 实现超时重试、连接失败告警等异常处理机制

### 8.3 文档整理
- 补充 README 和使用说明
